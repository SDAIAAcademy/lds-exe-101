# الذكاء الاصطناعي للتنفيذيين: إحاطة تطبيقية · المختبرات

ثلاثة مختبرات لمقرر أكاديمية سدايا **LDS-EXE-101**. المختبرات صفحات إرشادية بالعربية: الهدف، والملفات، وخطوات
بدقائقها، وأسئلة تحقق، ومهمة إضافية ✱، وملاحظات للمدرّب. لا كود يكتبه المشارك.

كل المختبرات في جهة واحدة: **هيئة قِسطاس للمواصفات والجودة**، هيئة افتراضية لشهادات المطابقة. كل الأسماء والأرقام
والطلبات مخترعة، وكل الملفات مصنفة «عام».

## ما يحتاجه المشارك

- متصفح، ومساعد مستضاف واحد: نموذج مستضاف مفتوح الأوزان، أو مساعد تجاري بخطته المجانية أو المعتمدة في جهته.
  لا يُنزَّل أي نموذج على الجهاز.
- بطاقة العمل التحضيري `files/prework_task_card.md` مملوءة: مهمة غير سرية من عمله، مصنفة قبل الإحاطة.
  نحو 30 دقيقة من التعلم الموجَّه.
- ورقة وقلم.

## صندوق قسطاس (المختبر 1.2)

`tools/sandbox.html` صفحة واحدة تعمل في المتصفح بلا شبكة ولا حساب. فيها ملفات الهيئة، وموجزا مهمتين متشابهتين
من خمس خطوات، والوكيل «مُنجِز». **مُنجِز ليس نموذجًا لغويًّا**: برنامج مكتوب السلوك يقلّد طريقة عمل الوكلاء،
ويعطي التشغيل نفسه في كل مرة لتقارن القاعة ملاحظاتها على شيء واحد. قواعده في صفحة المختبر، مطوية حتى ينهي
المشارك ورقته. يُشغَّل محركه نفسه تحت Node في `solutions/check_sandbox.mjs`.

الوكيل في منتج تجاري (المهمة الإضافية) يتغير سلوكه من تشغيل إلى آخر، ولم يُجرَّب هنا.

## للمدرّب: المفتاح والأدوات

- `solutions/answer_key.md`: كل ما زُرع في الملفات، وأين، وأي مختبر يكشفه، وكيف يُقيَّم.
- `solutions/key.json`: الأرقام نفسها، يكتبها المولّد.
- `solutions/score_claims.py`، `solutions/score_sort.py`، `solutions/score_questions.py`: مقيّمات أوراق المختبرين 1.1 و1.3.
- `solutions/run_all.py`: يعيد توليد الملفات ويتحقق أنها لم تتغير، ثم يشغّل كل ما سبق، ويطبع PASS أو أول اختلاف.

الأدوات بمكتبة Python القياسية وحدها، وتُشغَّل بـ`uv` من جذر المستودع؛ والفحص الآلي للصندوق يحتاج Node 22 أو أحدث:

```
uv run labs/_tools/prepare_files.py
uv run labs/solutions/run_all.py
node labs/solutions/check_sandbox.mjs
uv run labs/solutions/score_claims.py labs/solutions/claim_sheet_reference.csv
```

الأول يعيد كتابة `files/` و`tools/sandbox.html` وملفات الحل المرجعية ببذرة ثابتة (101): البايتات نفسها في كل تشغيل.

## ما لم يُشغَّل على نموذج لغوي

لم يُستدعَ أي نموذج لغوي في بناء هذه المختبرات. المسودة المساعَدة للمهمة البديلة كُتبت للمقرر لتقوم مقام ناتج
مساعد، والوكيل في الصندوق مكتوب السلوك. جرّب المهمة البديلة على المساعد الذي ستستخدمه القاعة قبل أول دفعة،
وانظر أي الادعاءات يخطئ فيها: قد تختلف عن المسودة، والفرق مادة جيدة للنقاش.
